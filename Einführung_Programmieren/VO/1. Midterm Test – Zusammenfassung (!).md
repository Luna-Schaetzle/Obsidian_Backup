## 1️⃣ Einführung (Foliensatz 01)

### Maschinensprache & Übersetzung
- **Computer** = Maschine, die Probleme durch Ausführen von Befehlen (*instructions*) löst.
- Die **CPU** kennt nur eine begrenzte Menge einfacher Maschinenbefehle → **Maschinensprache**. Unterschiedliche CPUs ⇒ unterschiedliche Maschinensprachen.
- Ein **Programm** = Folge von Befehlen zur Ausführung einer Aufgabe.
- ⚠️ *Alle* Programme müssen vor der Ausführung in Maschinensprache umgewandelt werden.

> [!tip] Compilieren vs. Interpretieren
> - **Compiler**: übersetzt das komplette Programm *vor* der Ausführung in eine ausführbare Datei (Folge von Maschinenbefehlen).
> - **Interpreter**: übersetzt Befehle *während* der Ausführung einzeln nacheinander und führt sie sofort aus.

### Eigenschaften von C
- Imperative Programmiersprache, **wenige Schlüsselwörter**, direkte Speicherzugriffe, sehr hardwarenah, schwaches Modulkonzept → mächtig, aber auch fehleranfällig (Vor- und Nachteil!).
- Geschichte: 1969 Dennis Ritchie & Ken Thompson (AT&T Bell Labs, für Unix). Versionen: **K&R-C 1978 → C89/90 → C99 → C11 → C18/C17 → C23**. In der LV: **C18**.
- Heute: Betriebssysteme (Linux), Systemprogrammierung, Embedded Systems, Spiele, Interpreter (Python, Ruby …). C ist Basis von C++, Objective C und beeinflusste Java, C#, Swift, Rust …
- Compiler gibt es auf fast allen Systemen (TIOBE-Index: C dauerhaft weit oben).

### Dateiarten & Werkzeugkette
- **Quelltextdateien** (`.c`): enthalten den Quellcode.
- **Headerdateien** (`.h`): Informationen für die Übersetzung, z. B. Definitionen von Datentypen und Funktionsdeklarationen.

```bash
gcc program.c                 # erzeugt a.out
gcc program.c -o program      # erzeugt Programm "program"
# LV-Konvention:
gcc -Wall -Wextra -Werror -Wpedantic -std=c18 hello_world.c -o hello_world
```

### Das erste C-Programm

```c
/* Das erste C-Programm */        // Blockkommentar /* ... */
#include <stdio.h>                // Präprozessordirektive: Inhalt von stdio.h einfügen
#include <stdlib.h>               // enthält EXIT_SUCCESS / EXIT_FAILURE

int main(void) {                  // Einstiegspunkt jedes C-Programms, gibt int zurück
    printf("Hello World!\n");     // Ausgabe auf Standardausgabe, \n = Zeilenumbruch
    return EXIT_SUCCESS;          // 0 = Erfolg; EXIT_FAILURE = Fehler
}
```

> [!important] Merkpunkte zu Hello World
> - Kommentare: `/* ... */` (Block) und `// ...` (Zeile) – haben keinen Einfluss auf den Ablauf.
> - `#include` wird vom **Präprozessor** per reiner **Textersetzung** verarbeitet, *bevor* der Compiler läuft.
> - Jede **Anweisung** endet mit `;`.
> - `printf` benötigt `stdio.h`; ohne `#include` → Kompilierfehler (typische Prüfungsaufgabe!).

### Zeichen in C
- Mindestens: Groß-/Kleinbuchstaben A–Z, a–z, Ziffern 0–9, Grafiksymbole, Whitespace (Leerzeichen, Tabs, Zeilenumbruch …).
- Moderne Compiler unterstützen erweiterte Zeichensätze (UTF-8, Umlaute, Emojis) – für Variablennamen aber vermeiden!

## 2️⃣ Vorschau (Foliensatz 02)

> [!warning] Disclaimer
> Die Vorschau ist eine **Kurzfassung** – für die Klausur die ausführlichen Folien der späteren Einheiten verwenden!

- **Motivation**: Werte speichern (→ Variablen), rechnen (→ Operatoren), abhängig vom Ergebnis verzweigen (→ if), Code wiederholen (→ Schleifen).
- **Variable** = benannte Speicherstelle mit: Datentyp, Name, Wert, Adresse, Gültigkeitszeitraum, Sichtbarkeitsbereich.
- Vor Verwendung muss eine Variable **deklariert** werden; ohne Initialisierung hat sie einen **zufälligen Wert**!
- Grundtypen: `char` (Zeichen/Ganzzahl), `int` (Ganzzahl mit Vorzeichen), `float`/`double` (Gleitkomma, einfach/doppelt).
- Operatoren: `=` (Zuweisung), `+ - * / %` (Arithmetik; `%` = Rest, z. B. `11 % 2 = 1`), Vergleichsoperatoren (`== != > < >= <=` → Ergebnis `int`: **0 = falsch, alles ≠ 0 = wahr**), logische `&& || !`.
- **printf**: `printf(Formatstring, Parameter)`; Platzhalter beginnen mit `%` (z. B. `%d` für `int`), `\n` = Zeilenvorschub.
- **if / else**: Block wird ausgeführt, wenn Bedingung ≠ 0.
- **while**: wiederholt den Körper, solange Bedingung ≠ 0 – Bedingung wird *vor* jedem Durchlauf geprüft.

```c
int i = 1;
while (i < 5) {
    printf("%d\n", i);
    i = i + 1;        // ohne Anpassung: Endlosschleife!
}
```

> [!example] Typische Übungsaufgaben
> - Zahl `n` auf `1 ≤ n ≤ 10` prüfen ("valid"/"invalid").
> - Minimum/Maximum von `x` und `y` mit if-Anweisungen bestimmen.
> - Zahlen 0…n absteigend/aufsteigend mit while ausgeben.
> - Anzahl der Teiler von `n` ermitteln.

## 3️⃣ Variablen und Datentypen (Foliensatz 03)

### Datentypen – Grundprinzip
- In C hat **jedes Datum einen genau definierten Typ**. Der Datentyp legt fest: **Wertebereich, Speicherrepräsentation (Bytes), erlaubte Operationen**.
- Dieselben Bits bedeuten je nach Typ etwas anderes: `11111111` = 255 (unsigned) **oder** −1 (signed, Zweierkomplement).

### Ganzzahl-Typen
- Interne Darstellung: **Zweierkomplement** am häufigsten; höchstes Bit = Vorzeichenbit.
- Rangordnung: `char < short ≤ int ≤ long ≤ long long`.

| Typ | min. Bits | min. Wertebereich |
| --- | --- | --- |
| `signed char` / `unsigned char` | 8 | −127…127 / 0…255 |
| `short` / `unsigned short` | 16 | −32.767…32.767 / 0…65.535 |
| `int` / `unsigned` | 16 | −32.767…32.767 / 0…65.535 |
| `long` / `unsigned long` | 32 | ±2.147.483.647 / 0…4.294.967.295 |
| `long long` / `unsigned long long` | 64 | ±9,22…·10¹⁸ / 0…18,4…·10¹⁸ |

- `char` ist je nach Implementierung ein Synonym für `signed char` oder `unsigned char`; `char`, `signed char`, `unsigned char` sind formal **drei verschiedene Typen**. Größe von `char` = immer 1 Byte; mit `char` kann gerechnet werden.
- `signed` ist (außer bei `char`) optional; `unsigned` **muss** explizit angegeben werden. Synonyme: `int` = `signed` = `signed int`; `unsigned int` = `unsigned` usw.
- C-Standard gibt nur **Mindestgrößen** an – tatsächliche Größe ist systemabhängig!
  - `limits.h`: `INT_MAX`, `INT_MIN`, `UINT_MAX`, `SHRT_MAX`, `LONG_MAX` …
  - `float.h`: `FLT_MAX`, `DBL_MAX`, `FLT_DIG`, `DBL_DIG` …
  - `stdint.h`: Integer mit fester Bitbreite.

### Aufzählungstypen (enum)
- `enum [Name] {Konstanten};` z. B. `enum color {RED, GREEN, BLUE};`
- Konstanten haben Typ `int`: erste = 0, sonst Vorgänger + 1; explizit zuweisbar (`SOUTH = 15` → `WEST = 16`).
- ⚠️ Compiler prüft **nicht**, ob ein zugewiesener Wert einer Aufzählungskonstante entspricht.

### Gleitkomma-Typen
- Begrenzte Genauigkeit ⇒ **Rundungsfehler** möglich.
  - `float`: mind. 6 signifikante Stellen; `double`: mind. 10 (meist 15); `long double`: erweitert.
  - `float` ⊂ `double` ⊂ `long long`… genauer: `float`-Werte ⊆ `double`-Werte ⊆ `long double`-Werte.

### Variablen im Detail
- **Adresse**: Variablen liegen in nummerierten Speicherzellen; Adresse der Variable = Nummer der ersten belegten Zelle.
- **Deklaration** legt Datentyp + Bezeichner fest; **Definition** = Deklaration + Speicherplatzreservierung (einfache Programme: Deklaration = Definition; Unterschied v. a. bei mehreren Dateien, Stichwort `extern`).
- **Bezeichner**: Buchstaben, Ziffern, `_`; muss mit Buchstaben/`_` beginnen; kein Schlüsselwort; C ist **case-sensitive**; Konvention: kleingeschrieben, sprechende Namen, Unterstriche, Englisch, keine Emojis, keine Abkürzungen.
- Reservierte Schlüsselwörter: `auto break case char const continue default do double else enum extern float for goto if int long register return short signed sizeof static struct switch typedef union unsigned void volatile while` (+ C99/C11-Erweiterungen wie `_Bool`, `inline`, `_Static_assert` …).

### Literale
- Ein Literal = konstanter Wert; Typ ergibt sich aus Art und Wert.

| Art | Beispiele / Regeln |
| --- | --- |
| Ganzzahl | Dezimal `123`, Oktal `0...` (0–7), Hex `0x`/`0X`; Suffixe `U`, `L`, `LL`, `UL` … (Großbuchstaben empfohlen!); ohne Suffix: kleinster passender Typ |
| Gleitkomma | `10.5` (double), `10.5f` (float), `.4`, `7.5e-1f`, hex z. B. `0xa.fp-1` (Exponent hier Pflicht); ohne Suffix = `double` |
| Zeichen | `'A'`, `'5'`, Escapes `'\n'`, `'\t'`, `'\''`; Typ ist **int** (Wert = Zeichensatznummer); `''` ist ungültig, `"B"` ist ein String, `B` ein Bezeichner! |
| Aufzählung | enum-Konstanten (s. o.) |

### Boolesche Ausdrücke
- Vor C99: `int` mit 0 = false, 1 = true.
- Seit C99: Typ **`_Bool`** (nur 0/1) + Header `<stdbool.h>` mit Makros `bool → _Bool`, `true → 1`, `false → 0`. Keine eigenen Literale (z. B. kein `1b`).

### printf im Detail
- Struktur: `%[flags][width][.precision][modifier]converter`
- Wichtige Converter: `d/i` (int), `u` (unsigned), `o`, `x/X` (Hex), `c` (Zeichen), `s` (String), `f`, `e/E`, `g/G` (double), `p` (Adresse), `%%` (Prozentzeichen).
- Modifier: `hh` (char), `h` (short), `l` (long), `ll` (long long), `z` (size_t), `L` (long double) …
- Flags: `-` linksbündig, `+` Vorzeichen, `0` Nullen auffüllen, `#` alternative Form, Leerzeichen.
- `width` = Mindestbreite (auch `*`), `.precision` = je nach Typ min. Stellen bzw. Nachkommastellen (bei `s`: max. Bytes).
- Rückgabewert = Anzahl der ausgegebenen Zeichen.

```c
printf("|%3d|\n", 1);     // |  1|
printf("|%-3d|\n", 1);    // |1  |
printf("|%03d|\n", 1);    // |001|
printf("|%5.2f|\n", 0.899); // | 0.90|
```

### scanf
- Liest Eingabefelder formatiert ein; **Adresse** der Variable via `&x` übergeben!
- Rückgabewert = Anzahl erfolgreich zugewiesener Werte (auf `!= 1` prüfen!).
- ⚠️ `double` einlesen mit `%lf`.

```c
if (scanf("%d", &i) != 1) {
    printf("Fehler beim Einlesen!\n");
    return EXIT_FAILURE;
}
```

> [!example] Klassische Fehler in scanf-Aufgaben
> `scanf("%d", var1)` → fehlendes `&`; `%s` statt `%d` für int; fehlender `&`-Parameter im printf (`printf("%d + %d = %d\n", var1 + var2)` → drei Platzhalter, nur ein Argument).

## 4️⃣ Operatoren und Ausdrücke (Foliensatz 04)

### Terminologie
- **Operatoren**: unär / binär / ternär; Präfix / Postfix / Infix; links- / rechtsassoziativ.
- **Ausdruck** (expression): Folge von Literalen, Bezeichnern, Operatoren; hat **Typ und Wert**, kann **Seiteneffekte** haben (Wert einer Variable, Dateiinhalt, Ausgabe).
- **Anweisung** (statement): Ausdruck + `;`. `2 + 6;` ist möglich, aber sinnlos; `i++;` sinnvoll (Seiteneffekt!).

### Zuweisung & Arithmetik
- `=` ist **rechtsassoziativ**; Zuweisungsausdruck hat Wert & Typ des *linken* Operanden *nach* der Zuweisung ⇒ `x = y = 3` und `x = x + 1` sind gültig.
- Arithmetik: unäre `+ -` rechtsassoziativ, binäre `+ - * /` linksassoziativ.
- ⚠️ Division/Restwert mit zweitem Operanden 0: **undefiniert** (bei Ganzzahlen).
- `5 / 2 = 2` (Ganzzahldivision schneidet ab!), `5.0 / 2.0 = 2.5`, `-5 / 2 = -2` (Richtung 0), `5 % 2 = 1`, `-5 % 2 = -1`.

> [!warning] Integer Overflow
> - **signed**: Überlauf = **undefiniertes Verhalten**!
> - **unsigned**: Rechnung modulo 2ⁿ (n = Bitzahl) ⇒ `UINT_MAX + 1 = 0`, `0 - 1 = UINT_MAX`.

### Inkrement / Dekrement
- `++x` (Präinkrement): Wert **nach** Erhöhung; `x++` (Postinkrement): Wert **vor** Erhöhung (analog `--`).

```c
int a = 3;
int b = 3 * ++a;  // a=4, b=12
int c = 3 * a++;  // a=5, c=12 (Wert vor Inkrement!)
```

### Vergleichs- und logische Operatoren
- Vergleichsoperatoren liefern `int`: **0 = falsch, 1 = wahr**.
- Logische Operatoren: `&&`, `||`, `!` – Ergebnis `int` (1/0); 0 gilt als falsch, **jeder Wert ≠ 0** als wahr.
- `&&` und `||` werden mit **Kurzschlussauswertung** (short circuit evaluation) ausgewertet: sobald das Ergebnis feststeht, wird der rechte Operand **nicht mehr** ausgewertet (⇒ Seiteneffekte rechts vermeiden!).

### Bitoperationen
| Operator | Bedeutung | Beispiel (`x=5=101₂`, `y=9=1001₂`) |
| --- | --- | --- |
| `&` | bitweises UND | `x & y = 1` |
| `\|` | bitweises ODER | `x \| y = 13` |
| `^` | bitweises XOR | `x ^ y = 12` |
| `~` | bitweise Negation | jede Bitposition invertiert |
| `<<` / `>>` | Shift links/rechts | `x << 1 = 10`, `x >> 2 = 1` |

- Kombinierte Zuweisungen: `+= -= *= /= %=`, `&= |= ^= <<= >>=`; z. B. `c *= a - 10` ⇔ `c = c * (a - 10)`.

### Bedingungsoperator
- Einziger **ternärer** Operator, rechtsassoziativ: `A ? B : C` – wenn A ≠ 0 ⇒ B, sonst C.
- Beispiel: `max_ab = (a > b) ? a : b;`

### sizeof
- Liefert Größe von Typen/Ausdrücken **in Bytes**, Typ `size_t` (vorzeichenlos, `stddef.h`, architekturabhängig).
- Der Ausdruck wird **nicht ausgewertet** (`sizeof(3/0)` legal!). Klammern bei Typen Pflicht; `sizeof x + y` = `(sizeof x) + y` wegen hoher Präzedenz!

### Operatorpräzedenz (hoch → niedrig)
1. Postfix: `() [] -> . ++ --` (links)
2. Präfix: `! ~ ++ -- + - * & sizeof (Typ)` (rechts)
3. `* / %` → 4. `+ -` → 5. `<< >>` → 6. `< <= > >=` → 7. `== !=` (alle links)
4. `&` → 9. `^` → 10. `|` → 11. `&&` → 12. `||` (alle links)
5. `?:` (rechts) → 14. Zuweisungen `= += -= *= /= %= &= ^= |= <<= >>=` (rechts) → 15. Komma `,` (links)

- Beispiele: `a && b || c < 0` ⇔ `(a && b) || (c < 0)`; `6 * 5 + 4 << 3 / 2` ⇔ `((6*5)+4) << (3/2)`; `a / b % c` ⇔ `(a / b) % c`.
- ⚠️ Präzedenz ≠ Auswertungsreihenfolge der Operanden: bei `1*2 + 3*4` ist nicht festgelegt, welcher Teilausdruck zuerst ausgewertet wird.

### Typumwandlung (Casting)
- **Explizit**: `(Typname) Ausdruck`, z. B. `(int) 5.6` → 5; `(double)(4/3)` → 1.000000 (Division läuft *vor* dem Cast!).
- **Implizit**: automatisch bei Zuweisungen/Operationen mit unterschiedlichen Typen (nur zwischen verträglichen Typen).
- Regeln (Auswahl):
  - Arithmetisch → `_Bool`: 0 bleibt 0, alles andere → 1.
  - Ganzzahl → **unsigned**: Modulo-Rechnung (`-1` → `UINT_MAX`); `1025` → `(unsigned char)` = 1.
  - Ganzzahl → **signed**: Wert unverändert, falls darstellbar; sonst implementierungsabhängig.
  - Gleitkomma → Ganzzahl: Nachkommastellen **abschneiden** (Richtung 0); außerhalb des Bereichs = undefiniert.
  - Gleitkomma ↔ Gleitkomma: exakt, wenn möglich; sonst nächstliegender Wert; außerhalb = undefiniert.
- **Gewöhnliche arithmetische Typumwandlung** (bei binären Operatoren, nicht bei `&&`/`||`/Zuweisung): höherer Typ gewinnt; bei Ganzzahlen zuerst **Integer Promotion** (kleine Typen → `int`, sonst `unsigned int`, ohne Wertänderung).
- Rangfolge bei gemischten signed/unsigned: unsigned mit mindestens gleichem Rang "gewinnt" (→ signed wird unsigned!); kann signed alles darstellen → signed.

> [!example] Datentypen von Ausdrücken (Aufgabe)
> `2 + 5.0` → double; `5.0f + 5` → float; `1.0f + 2.0` → double; `(int)10.0 + 5.0f` → float; `2 + 3UL` → unsigned long; `'C' + '-' + 'V' + '0'` → int; `(char)(2+4)` → char; `3 > 5` → int; `(short)10 + 3U` → unsigned.

## 5️⃣ Kontrollstrukturen (Foliensatz 05)

### Arten von Anweisungen
- **Block** `{ ... }` (danach **kein** Semikolon!), syntaktisch wie eine Anweisung, schachtelbar.
- Ausdrucksanweisung (Ausdruck + `;`), Selektion (if, switch), Iteration (while, do-while, for), Sprung (break, continue, return, goto).

### if-Anweisung
- `if (Ausdruck) Anweisung1 else Anweisung2` – Ausdruck ≠ 0 ⇒ Anweisung1, sonst Anweisung2; else optional; mehrere Anweisungen → Block!
- **Mehrfach-Selektion**: `else if`-Ketten; Bedingungen von oben nach unten, erste wahre gewinnt.

> [!warning] Dangling else
> Ein `else` gehört immer zum textuell **letzten freien if** im selben Block! Deshalb: **immer Blöcke verwenden**.

### switch-Anweisung
- `case`-Marken brauchen **konstante ganzzahlige Ausdrücke**, alle unterschiedlich; `default` optional.
- Passt ein case → dort weiter ausführen; **`break`** beendet die switch; fehlt es ⇒ **"fall through"** (alle folgenden Anweisungen bis zum nächsten break/Ende).
- Bewusstes Fall-Through nutzt man z. B. für Gruppen (Mo–Fr = "business day", Sa/So = "weekend").

```c
switch (option) {
    case 1:  printf("option 1\n"); break;
    case 2:  printf("option 2\n"); break;
    default: printf("unknown option!\n"); break;
}
```

- switch prüft nur **Gleichheit** ganzzahliger Werte; if kann beliebige Bedingungen. Switch ist übersichtlicher und leichter erweiterbar.

### while-Schleife
- Kopfgesteuert: Bedingung wird **vor** jedem Durchlauf geprüft (Körper kann also nie ausgeführt werden).
- Im Körper muss sich etwas ändern, sonst **Endlosschleife**; mehrere Anweisungen → Block.

### for-Schleife
- `for (Ausdruck_1; Ausdruck_2; Ausdruck_3) Anweisung`
  - Ausdruck_1: Initialisierung (Variablen dürfen hier deklariert werden) – einmalig.
  - Ausdruck_2: Schleifenbedingung (vor jedem Durchlauf).
  - Ausdruck_3: Anpassung (nach jedem Durchlauf).
- Alle drei Ausdrücke dürfen fehlen; fehlt Ausdruck_2 ⇒ Bedingung immer wahr (Endlosschleife, Abbruch via `break`).
- **Komma-Operator**: mehrere Initialisierungen/Anpassungen: `for (int i = 0, j = 9; i < j; ++i, --j)`.
- Leerer Körper: `for(...);` oder `for(...){}`.
- for ↔ while sind äquivalent umformbar; Faustregel: for bei definierter Bereichs-Schrittweite-Durchläufen, while bei reinem Endkriterium.

> [!warning] Gleitkommazahlen als Schleifenvariable
> `for (float i = 0.0f; i != 1.0f; i += 0.1f)` terminiert **nie** (Rundungsfehler: 0.1f ist nicht exakt darstellbar)! Lösung: Ganzzahl-Schleife und durch `10.0f` teilen oder `<` statt `!=` verwenden.

### do-while-Schleife
- Fußgesteuert: Körper wird **mindestens einmal** ausgeführt, danach Bedingung prüfen; Semikolon am Ende Pflicht.

```c
do {
    ++digits;
    value /= 10;
} while (value);     // zählt Ziffern einer Zahl
```

### Endlosschleifen
- `while(1) {...}` oder `for(;;) {...}`; Abbruch via `break`, `return` oder `exit`.

### Sprunganweisungen
- **break**: verlässt die umgebende Schleife oder switch (nur dort erlaubt).
- **continue**: überspringt den Rest des Schleifenkörpers, springt zur nächsten Bedingungsprüfung (nur im Schleifenkörper; bei for wird Ausdruck_3 noch ausgeführt!). Sparsam verwenden.
  - ⚠️ Klassiker: `continue` *vor* `i++` in einer while-Schleife ⇒ Endlosschleife.
- **goto Sprungmarke;** – Sprung zu `Marke:`; praktisch nie sinnvoll (einzige Ausnahme z. B. Ausbruch aus verschachtelten Schleifen); jedes Programm geht auch ohne goto.
- **return** beendet eine Funktion (→ Foliensatz Funktionen).
