Booth-Algorithmus (Multiplikation im Zweierkomplement)

Register: A (n Bit, Start 0), Q = Multiplikator, Q₋₁ (Start 0), M = Multiplikand. Je Schritt auf Q₀Q₋₁ schauen: 01 → A = A + M, 10 → A = A − M, 00/11 → nichts. Danach arithmetischer Rechtsshift von (A, Q, Q₋₁). n Schritte, Ergebnis = A:Q (2n Bit).
